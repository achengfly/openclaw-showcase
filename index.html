OpenClaw 多 Agent 展示

统一调度、分层记忆、可控执行

这个页面用于展示 OpenClaw 在个人工作台里的协作方式：所有能力统一接入网关，Agent 按职责拆分，敏感动作有确认，配置经验沉淀为可复用的操作规范。

统一入口

所有请求都先进入 OpenClaw Gateway，再按能力与风险等级分发。

多 Agent 协作

业务 Agent 聚焦领域工作流，开发 Agent 负责实现与审查闭环。

记忆分层

长期知识、阶段上下文、瞬时会话分别治理，避免无序堆积。

架构图

Agent 架构说明

所有 Agent 描述统一中文化，便于在展示场景中直接沟通职责与边界。

调度核心

OpenClaw Gateway

统一接收请求、路由 Agent、治理能力边界，并在敏感场景触发确认流程。

📓 日记 Agent

事件/情绪/反思，访谈引导+深度整理

💰 财务 Agent

记账/资产/余额/统计，双重校验+预算提醒

📊 交易 Agent

仓位/交易/风控，敏感操作需确认

📡 信息 Agent

情报/研究/摘要

🛠️ 开发 Agent

Codex编码 + Claude Code Review

步骤一：需求进入网关

用户请求先被结构化，再决定是走只读、执行还是需要确认的高风险流程。

步骤二：路由到专属 Agent

网关按领域能力选择目标 Agent，并附带必要上下文与记忆层数据。

步骤三：结果回传与记录

输出统一回流到网关，更新记忆层并保留审计信息，避免多入口失控。
